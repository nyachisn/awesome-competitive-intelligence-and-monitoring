# Contribution Guidelines

Thank you for considering contributing to Awesome Competitive Intelligence!

## Guidelines

- **Quality over quantity** - Only suggest tools/resources you've personally used or thoroughly vetted
- **Be objective** - This list should help users find the best tools, not promote specific vendors
- **Keep descriptions clear** - One concise sentence explaining what the tool does
- **Check for duplicates** - Search existing entries before adding
- **Maintain alphabetical order** - Within each category
- **Follow the format** - Match the existing entry style

## Adding an Entry

1. Fork this repository
2. Add your entry in the appropriate category
3. Use this format: `- **[Tool Name](URL)** - Brief description.`
4. Ensure the link works and points to the official site
5. Submit a pull request with a clear title

## What to Include

✅ **DO include:**
- Established tools with proven track records
- Free and paid options
- Open-source projects
- Educational resources (books, courses, guides)
- Frameworks and methodologies

❌ **DON'T include:**
- Affiliate links
- Self-promotion without value
- Broken or dead links
- Tools that don't focus on competitive intelligence
- Duplicate entries

## Quality Standards

- Links must be active and functional
- Commercial tools should have a website and clear value proposition
- Open-source projects should have active maintenance (commits in last 6 months)
- Resources should be high-quality and relevant

## Review Process

Maintainers will review PRs within 7 days. We may ask for changes or clarification before merging.

Thank you for helping make this list awesome! 🎉
